Mortgage Credit Risk Assistant
Overview

The Mortgage Credit Risk Assistant is an AI-powered application that estimates a borrower's 12-month probability of mortgage default using a calibrated Weight of Evidence (WOE) logistic regression model.

The application combines traditional credit risk modeling with modern AI-ready architecture, providing both accurate risk predictions and transparent explanations of the factors driving each prediction.

Features
Predicts 12-month mortgage probability of default (PD)
Weight of Evidence (WOE) feature transformation
Calibrated logistic regression model
Risk tier classification
Feature contribution analysis
Transparent model explanations
Interactive Streamlit interface
AI-ready architecture for conversational explanations (planned)
Dataset

Freddie Mac Single-Family Loan-Level Dataset

Population:

Wisconsin mortgages
Origination years 2020–2022

Prediction Target:

12-month mortgage default
